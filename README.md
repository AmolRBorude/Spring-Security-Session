# Spring Security Learning Project

This project is created to learn the basics of **Spring Security** with Spring Boot.

## Technologies Used

- Java 17
- Spring Boot
- Spring Security
- Spring Web
- Maven
- Postman
- Eclipse IDE

## Project Features

- Basic Spring Security authentication
- Username and password authentication
- Securing REST APIs
- HTTP Basic Authentication
- Testing secured APIs using Postman
